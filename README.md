# Sri Ramlingeshwar Prassanna — Free Temple Website

## Included
- Modern responsive homepage
- Sticky header + in-page navigation
- Hero banner
- Visitor Insights
- About section
- Daily Pooja timings
- Festivals and special occasions
- Image/video gallery
- Video modal playback
- Articles listing + 3 detail pages
- Poojari profile page
- Support/donation placeholder
- Contact section
- No framework, database or paid library required

## Run locally
Open `index.html` in a browser. Everything works as a static site.

## Free hosting
Recommended: GitHub Pages.
1. Create a GitHub repository.
2. Upload all files/folders.
3. In Settings → Pages, select the main branch/root folder.
4. GitHub will provide a free `github.io` address and HTTPS.
5. Later connect a custom domain when you purchase one.

## Before publishing
Replace every `[Add ...]` placeholder with verified temple information.
Replace sample pooja times and visitor numbers with actual data.
Replace the sample YouTube video IDs with the temple's real videos.
Add real temple photos in the gallery.
Add a verified donation/payment method only after the temple's banking/organization details are ready.
